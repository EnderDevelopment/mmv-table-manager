# MMV Mobile Movement Script

This script provides mobile movement functionality for Roblox games, including player movement data management, movement handling, jumping functionality, and movement updates.

## Installation

1. Open Roblox Studio.
2. Create a new script in ServerScriptService or StarterPlayerScripts.
3. Copy the contents of `src/MMVMobileMovement.lua` into the new script.

## Usage

The script automatically initializes when a player joins the game and handles movement and jumping events. No additional setup is required.
